# 🎂 Calendario de Cumpleaños - Familia Cuenca

Este proyecto es una página web que muestra un calendario de cumpleaños y permite enviar felicitaciones por WhatsApp con un solo clic.

## 🚀 Cómo usar
1. Edita `birthdays.json` para agregar o quitar cumpleaños.
   - Formato obligatorio: `"DD-MM"`
   - Año opcional: `"anio": 1990`
2. Sube los cambios a GitHub.
3. Activa GitHub Pages:
   - Ve a **Settings → Pages**.
   - En **Source**, selecciona `Deploy from a branch`.
   - Elige la rama `main` y carpeta `/ (root)`.
4. Guarda y abre la URL que GitHub te dará, por ejemplo:
https://TU_USUARIO.github.io/cumpleanos-familia-Cuenca


Copiar código

## 📌 Funcionamiento
- Si hoy es el cumpleaños de alguien, aparecerá un botón verde **"Enviar Felicitación"**.
- Al hacer clic, se abrirá WhatsApp Web o la app con el mensaje listo para enviar.
- Solo debes presionar **Enviar**.

## 📂 Estructura
- `index.html` → Página web con el calendario y botón de WhatsApp.
- `birthdays.json` → Lista editable de cumpleaños.
- `README.md` → Documentación del proyecto.
